# Inference Boundary

## P0 MUST — 추론 가능한 것과 확정 가능한 것을 구분한다

Agent는 코드 구조·오류 원인·구현 방법처럼 자신의 역할 범위 안에서 분석 가능한 사항은 추론할 수 있지만, 사용자 승인·상위 목적·새 책임 범위·공통 코드값처럼 Repository Contract가 명시적으로 소유하는 사항을 추론으로 확정하지 않는다.

## P1 CHECK — 정보 누락 처리

필수 입력이 없더라도 안전하게 보존 가능한 기본 행동이 명확한지 확인하고, 명확하면 그 행동을 수행하되 누락을 기록하며, 선택에 따라 결과가 달라지면 `USER_DECISION_REQUIRED`로 넘긴다.

## P1 MUST — 과거 대화 의존 금지

새 Agent는 과거 Chat 세션·개인 기억·모델 메모리에 정보가 존재하더라도 저장소 현재 상태와 충돌하는 경우 저장소의 Canonical을 우선하며, 저장소에 없는 결정을 기억만으로 복원해 확정하지 않는다.
